12관절 사족보행로봇 공연 제어

음악 재생과 동시에 USB로 연결된 마이크로비트1에 공연 번호를 전송합니다.

1. 마이크로비트1 연결

● 연결되지 않음
Chrome 또는 Edge에서 실행하세요. MakeCode가 마이크로비트를 사용 중이면 MakeCode 탭을 닫고, USB 케이블을 뺐다가 다시 연결한 뒤 시도하세요.

2. 음악 등록

여러 파일을 한꺼번에 선택할 수 있습니다. 파일명 맨 앞의 번호를 공연 번호로 인식합니다.
예: 1. 시작 음악.mp3, 2. 두 번째 음악.mp3 … 8. 여덟 번째 음악.mp3
번호가 없는 파일, 1~8 이외의 번호, 중복 번호 파일은 등록하지 않고 결과를 안내합니다. 음악과 지연값은 서버, 쿠키, localStorage에 저장하지 않으며 새로고침하면 모두 초기화됩니다.

3. 공연 실행

● 연결되지 않음
등록된 음악을 선택하세요.

통신 기록

음악별 지연 보정값

음악을 업로드하면 공연 번호에 맞춰 지연값 입력칸이 생성됩니다.
음악 지연 보정이란?
로봇과 음악의 시작 시점을 맞추기 위한 기능입니다.
양수값은 공연 번호를 먼저 전송한 뒤 해당 시간만큼 기다리고 음악을 재생합니다. 로봇이 음악보다 늦게 움직일 때 사용합니다.
음수값은 음악을 먼저 재생한 뒤 절댓값만큼 기다리고 공연 번호를 전송합니다. 로봇이 음악보다 빨리 움직일 때 사용합니다.
예: 100ms는 로봇 신호를 먼저 보내고 0.1초 뒤 음악 재생, -100ms는 음악을 먼저 재생하고 0.1초 뒤 로봇 신호 전송입니다.
저장한 값은 현재 화면이 열려 있는 동안 유지되며, 새로고침하면 초기화됩니다.
